# 🚗 Sistema de Carros - Java

Projeto desenvolvido para praticar **orientação a objetos** em Java, com foco em **herança**, **encapsulamento** e **sobrescrita de métodos**.

## 📋 Descrição

O sistema permite cadastrar modelos de carros com seus preços ao longo de 3 anos, calculando automaticamente o **menor** e o **maior** preço do período.

## 🧠 Conceitos praticados

- Classes e objetos
- Encapsulamento (`private`, getters e setters)
- Herança (`extends`)
- Sobrescrita de métodos (`@Override`)
- Arrays
- Laços de repetição (`for-each`)
- Lógica de comparação (menor/maior)
